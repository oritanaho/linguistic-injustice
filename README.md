# 研究会　概要

本研究会では、話し方や言語変種にもとづき不利益が体系的に生じる「言語的不公正」を、日本の文脈で実証的に検討します。初年度は、琉球諸語を主な対象に、教育・社会的態度・行政施策などの事例を分野横断で収集・共有し、「論点マップ」として整理することを目指します。

本研究会は日本言語学会の特設研究会として承認され、2026年10月から活動を開始しました。

## 「言語的不公正」とは

言語的不公正とは、話し方や言語変種にもとづき、伝達の負担・信用性の判断・資源へのアクセスなどが体系的に不利に配分されている状態を指します。この観点は、教育・雇用・メディア・司法・医療・行政手続といった制度的場面から、契約や窓口での応対、近隣づきあいといった日常生活の細部、さらには言語学者自身の調査・研究の実践にまで関わりうるものです。

## 取り組む作業（2026年１0月〜2027年9月予定）

本研究会では、次の二つの作業に取り組みます。

1. **事例の収集と共有**：琉球諸語における言語的不公正が現れる場面（教育、社会的態度、行政・条例、当事者の経験など）について、構成員および外部講師の知見をもとに事例を収集・共有します。
2. **論点の切り分け**：収集した事例を、(a) 現時点での言語研究の枠組みで実証的な知見を提供できる論点、(b) 言語研究の問いでありながら今後の研究を要する論点、(c) 政治学・社会学・法学など言語学以外の知見を参照すべき論点に切り分け、「論点マップ」として可視化します。

本研究会は、法制度への提言そのものを目的とはせず、その手前にある実証的な基盤づくり――言語的不公正の実態を可視化し、そのうち言語研究の知見が制度改善に寄与しうる論点と、言語研究だけでは答えを出せない論点とを切り分ける作業――に徹します。将来の学際的な議論に耐えうる知的基盤を、日本言語学会コミュニティの中で育てることをめざします。

なお、本研究会は特定の地域・立場を代表するものではありません。本研究会でなされる言説の学問的妥当性は、日本言語学会が保障するものではありません。
